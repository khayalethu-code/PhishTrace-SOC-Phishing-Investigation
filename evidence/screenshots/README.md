# Investigation Screenshots

This directory will contain genuine screenshots documenting the PhishTrace project setup and investigation.

## Screenshot Guidelines

- Capture screenshots directly from the applications used.
- Use clear, descriptive filenames.
- Redact personal information and sensitive configuration before publication.
- Ensure screenshots support the findings documented in the report.
- Never fabricate screenshots or alter evidence to imply an event occurred.

Screenshots will be added as the corresponding project milestones are completed.
